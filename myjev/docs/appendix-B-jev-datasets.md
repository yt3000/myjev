# 需求附件 B · Jev 测试数据集与评测口径（固化留存）

用途：R3 能力对比中 Jev 列的唯一数据源；`myjev/providers.py` 的 `JEV_BASELINE` 字段必须逐条回指本附录。

## B.1 官方公开评测集
- 出处：evals.typesafe.ai（TypeSafe 官方评测页）；官方博客宣称在其公开案例上一致率 **88.3%**。
- 第三方引用形态：OpenJev 评测矩阵中拆出 **"102 个公开 TypeSafe 案例行"** 作为子集（附录 C）——这是目前社区可交叉复现的公共锚点。
- **留存状态：原始 102 行明细当前未离线获取**（官方页面需外网）。

### B.1.1 导入契约（对接 01 §3.2 / datasets 注册表，kind=`jev-102`，fields_ver=1）
```
data/datasets/<ds-id>.jsonl，每行：
{ "case_id": "ts-0001",
  "context": "<任意类型化上下文，object|string>",
  "question": { "type": "choice|noul|score",
                "options": ["..."],        // choice 必填
                "anchors": ["低","中","高"] // score 可选
                "text": "<问题描述>" },
  "gold": null 或 标注答案,                // 官方若未公布答案则为 null
  "source_url": "https://evals.typesafe.ai/..." }
```
使用规则：`gold=null` 时该集只能做**同分布对照**（MyJev 输出 vs 官方宣称/其他方输出的一致度），**不得表述为准确率**；`gold` 齐备后才升级为三方同集复测。获取途径与落地时间在 B.4 修订记录追加。

## B.2 官方宣称指标（引用必带"宣称"）
| 指标 | 值 | 口径 |
|---|---|---|
| 公开案例一致率 | 88.3% | 官方自测，evals.typesafe.ai 案例集 |
| 真实业务流一致率 | 67.8%（4 个业务流均值） | 第三方（ic.work 2026-09-18 汇总），分布与 B.1 不同，禁止同框比高低 |
| 延迟 | 70–500 ms | 官方口径；bench 中取 285 ms 区间代表值（providers 已标注） |
| 校准 | RLCD 训练纠偏（宣称） | 无逐头 ECE 公开数值；bench 记 0.01"宣称值" |
| 扰动鲁棒 | 未公开 | 雷达图按保守 3 分计（换算规则见 [算法规格]§13.3） |

## B.3 基准锚点说明
官方称以 GPT-6 Astra 与 Claude Fable 5.1 的共识概率为 RLCD 训练锚点——即其"一致率"的比较对象是大模型共识而非人工金标；解读 R3 结论时须携带此前提。
