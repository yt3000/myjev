版本 3.1（交付物重拆解稿） · 2026-09-22 · 变更：按用户裁决以"**服务后台 / 管理后台 / 测试 App**"三交付物为顶层结构重排全部文档；两进程拆分 ⇒ 新增发布热加载契约；维持"不鉴权、仅本机监听"；测试 App 定为独立 Web 应用（撤销独立 API 客户端交付，示例并入手册附录）；本轮交付仍 = 文档定稿，代码差异登记 05。

## 1. 交付物清单（定稿口径）

| # | 交付物 | 形态 | 职责 | 端口/位置 |
|---|---|---|---|---|

**本轮不交付**（非目标）：鉴权（仅绑定 loopback 作为安全边界）、独立 API 客户端库、运维监控 UI（access_log 数据保留，UI 后置）、数据飞轮导入、真实 Jev 云调用、多实例高可用。

## 2. 进程拓扑与共享

```
浏览器 ──双击──▶ [C 测试App 静态页] ──fetch(8091)──▶ [A 服务后台]
浏览器 ─────────▶ [B 管理后台 8090]  ──写──▶ data/myjev.db(WAL) ◀──读/写日志── [A]
                       └─发布: bump version_epoch              └─每2s轮询epoch→热加载工件
                                data/artifacts/<task>/<ver>/model.pkl (sha256 登记于库)
```
- 单 venv、单代码包、两个入口（`create_runtime_app()` / `create_admin_app()`），依赖不对等：A 只需推理栈（numpy+lightgbm+fastapi），B 含训练与 bench。
- SQLite 双进程写分离（WAL 支持跨进程读写，`busy_timeout=5000`）：A 只写 decisions/access_log；B 只写 tasks/model_versions/buffer/datasets/bench_runs/publish 事件；互不越表（03 §5）。
- CORS：A 允许 `null`（file:// 打开）与 `http://127.0.0.1:*` 源；B 不开 CORS（自源使用）。
